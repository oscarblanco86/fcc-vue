# 🚀 Vue 3 + Tailwind CSS - Mini Challenges

Este repositorio contiene pequeños desafíos e interactividades construidos durante el curso de **Vue.js de freeCodeCamp**. 

El objetivo de estas prácticas es dominar los conceptos fundamentales de Vue 3 (Composition API) combinados con Tailwind CSS para el diseño de interfaces modernas y dinámicas.

---

## 🛠️ Tecnologías Utilizadas

* **Vue.js 3** (mediante CDN con Composition API)
* **Tailwind CSS v4** (mediante CDN)
* **HTML5**

---

## 💻 Desafíos Incluidos

### 1. First Vue App
Una interfaz sencilla que muestra el saludo dinámico utilizando reactividad básica (`ref`).

### 2. Challenge 01 - 404 Error Page
Diseño de una pantalla de error 404 estilizada al estilo *Dark Mode* que demuestra la interpolación de texto con Vue y utilidades de centrado y tipografía con Tailwind CSS.
